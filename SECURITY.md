# Security policy

## Supported versions

Only the latest released version receives security fixes. Update to that version
before checking whether a reported issue still occurs.

## Report a vulnerability

Use GitHub private vulnerability reporting for
[SergeSerb2/OpenYourMac](https://github.com/SergeSerb2/OpenYourMac/security).
Open the repository's **Security** tab, select **Report a vulnerability**, and
submit a private report. Do not put vulnerability details in a public issue.
If that option is unavailable, contact [@SergeSerb2](https://github.com/SergeSerb2)
through GitHub to arrange a private channel before sharing details.

Include:

- The OpenYourMac version or source commit, macOS version, and Mac architecture.
- The affected app, engine, CLI, config, or release asset.
- Steps to reproduce and the expected and observed results.
- The security impact and any limits or access needed to reproduce it.
- A minimal example and relevant logs, with personal data and secrets removed.

Accessibility grants broad control of windows and input. Explain whether a report
requires that permission or a terminal that already has it. Do not send passwords,
tokens, private documents, or unreviewed window-title logs.

The maintainer will review reports and coordinate fixes and disclosure through
GitHub. This project does not promise a fixed response deadline.
